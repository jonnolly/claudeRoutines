# Daily AI tip — 2026-10-26 (Tip #1)

## Today's tip: stop being the test suite
**Time: ~10 minutes. Do it once, in the Trace Trimmer repo.**

You already discovered the single most important practice in agentic coding by yourself. In your
own Trace Trimmer task you wrote:

> "Make a rule that will definitely see whenever I start claude in this folder that the start-time
> must always be under 1 second. Test this each time you make a change… you must keep trying until
> you do fulfill this requirement."

That is exactly Anthropic's lead best practice — "give Claude a check it can run" is described as
*"the difference between a session you watch and one you walk away from."* But you wrote it as prose
inside one task, so it applied once, to one task, and only while you were watching. Make it
permanent and it applies to every run, including the unattended ones you want later.

**The 10 minutes:** open Claude in the Trace Trimmer repo and paste this.

```
Create scripts/check.sh as the single verification command for this repo. It must exit non-zero
on failure and print numbers, not opinions:
  1. run the existing tests (find them; if there are none, create one that loads a sample
     insight-format trace and asserts the parsed start/end times)
  2. measure cold start-up time and FAIL if it is over 1.0s, printing the measured seconds
Then add to CLAUDE.md, nothing more:
  - Run ./scripts/check.sh after every series of code changes; iterate until it passes.
  - IMPORTANT: start-up must stay under 1.0s. If it regresses, report the measured number.
  - Show me the check output as evidence; never report success without it.
Run ./scripts/check.sh now and show me the output.
```

**Why this one first:** it is the prerequisite for everything you asked about — multiple agents,
assigned roles, agents that keep working. An agent that can't tell whether it succeeded cannot be
left alone, so without the check, "continuously working agents" just means more output for you to
inspect. With it, the loop closes by itself. The 2026 research agrees from the other direction:
individual AI output rose ~98% in the DORA/Faros data while actual delivery stayed flat, because
the work piled up at review. Your review time is the scarce resource, not Claude's.

**Tomorrow builds on this**: turning that check into a hard gate (a Stop hook), which is what makes
a genuinely unattended run safe.
