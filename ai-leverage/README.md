# ai-leverage

State for the daily "one AI tip" routine.

- `PROFILE.md` — what's known about how John works and uses AI. Observed vs inferred vs needs-confirming.
- `QUESTIONS.md` — prioritised question backlog. Only <=15-min-answerable questions get asked. Answers land here.
- `PLAYBOOK.md` — ranked pool of practices, with primary sources, plus a "deliberately NOT recommending" list
  of advice that has gone stale.
- `TIPS-LOG.md` — what was served when, and whether it stuck.

## What each run does

1. Read all four files.
2. Fold any new answers in `QUESTIONS.md` into `PROFILE.md`; re-rank `PLAYBOOK.md`.
3. Serve the top unserved practice as **one** tip: <=15 min of doing, concrete commands, tailored to a live project.
4. Ask at most 3 questions from the top of the backlog.
5. Log it in `TIPS-LOG.md`, commit, and notify.

## Constraints (from John)

- <=15 min/day. Earning beats workflow polish; if a tip doesn't plausibly move money or reliability, it waits.
- **Never create tasks or routines on his behalf** — propose them, he schedules them so they don't collide with
  value-adding work.
- No "go read this" tips. He already has three unread TLDR newsletters a day.
