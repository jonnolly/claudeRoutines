## The key pattern spotted
Feature specs are being written **as Claude prompts inside TickTick task descriptions**, then
presumably pasted into Claude Code. Example (Trace Trimmer, "reduce start-up time"):

> *"Make a rule that will definitely see whenever I start claude in this folder that the start-time
> must always be under 1 second. **Test this each time you make a change.** If it doesn't fulfill this
> requirement, you must keep trying until you do fulfill this requirement."*

This is a hand-rolled version of three real mechanisms: **CLAUDE.md** (the invariant), a **hook**
(the enforcement), and a **skill** (the repeated procedure). Anthropic's own guidance flags exactly
this: *"Every time X, always do Y" in CLAUDE.md should be a hook*, and instructions are not
reliable guardrails. Same thing happened with the Insight CAN converter file-format spec — it's
restated at length in a task description instead of living in the repo.
