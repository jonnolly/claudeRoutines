# claudeRoutines

State and output for John's scheduled Claude routines.

## Daily AI-Practice Tip

A scheduled routine fires each morning (alongside the email review) and delivers
**one tip per day** on using Claude / AI more effectively — tailored to how John
actually works, and biased toward things he is *not already doing*.

| Path | Purpose |
|---|---|
| `ROUTINE.md` | How the daily run should operate. Read this first on each firing. |
| `profile/claude-usage-profile.md` | What we know about John's setup, workflow and goals. |
| `profile/QUESTIONS-FOR-JOHN.md` | Open questions; answers get folded back into the profile. |
| `tips/INDEX.md` | Ledger of every tip delivered. Never repeat one. |
| `tips/` | Full text of each day's tip. |
| `research/tip-backlog.md` | Ranked candidate tips, pre-researched, so mornings are fast. |
| `research/sources.md` | Source list behind the backlog. |
