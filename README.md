# claudeRoutines

Durable state for John's Claude cloud routines.

## ai-coaching/
Daily AI-workflow coaching routine. One tailored tip per day at the start of the day,
15 minutes maximum, aimed at output that earns money rather than workflow polish.

- `ROUTINE.md` — operating procedure for each run, and the boundaries.
- `profile.md` — what we know about how John works. The routine's memory.
- `questions.md` — ranked calibration questions, highest value at top.
- `tips-log.md` — every tip delivered, so none repeat.
- `sources.md` — the research base behind the tips.
