# claudeRoutines

Version-controlled state for John's scheduled Claude routines.

- `ai-coach/` — the daily "one AI workflow tip" routine.
  - `PROFILE.md` — standing context about John's work, tools and constraints.
  - `BACKLOG.md` — ranked, time-boxed backlog of tips and open questions.
  - `TIPS.md` — what has already been delivered (so nothing repeats).
  - `ROUTINE.md` — the protocol each daily run follows.
