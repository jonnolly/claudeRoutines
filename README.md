# claudeRoutines

State for John's Claude cloud routines.

## `ai-coach/`
The daily "one AI tip per day" routine, delivered in the morning email-review slot.

- `RUNBOOK.md` — what each run must do, in order. **Read this first.**
- `profile.md` — what's known about how John works and uses AI, plus the open gaps.
- `tips-backlog.md` — ranked tip queue; one delivered per day, re-ranked each run.
- `questions-backlog.md` — ranked questions, ≤5 min of answering per morning.
- `delivered-log.md` — what was sent, what came back.
- `sources.md` — research read, with dates; refresh every ~2 weeks.

Standing rule: this routine never creates tasks, routines or calendar entries on John's
behalf. It suggests; he schedules.
